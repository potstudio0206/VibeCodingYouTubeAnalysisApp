配信アーカイブ 解析ツール　使い方
==================================

YouTube配信のアーカイブから、次のものを時間軸のグラフ（ヒートマップ／折れ線）にして、
見どころ候補と一緒にレポートにします。
　・コメント量、コメントの加速度、同じコメントが流れる確率
　・声の大きさ、喋る量
　・画面の「RANKED MATCH」を検知して、序盤（雑談・練習）と後半（実践）の比較、試合ごとの一覧

■ 最初の1回だけ（準備・10分ほど）
1. Python をインストール
   https://www.python.org/downloads/ から「Download Python」を押してインストール。
   ※インストール画面の一番下「Add python.exe to PATH」に必ずチェックを入れる。
2. このフォルダの setup.bat をダブルクリック
   必要な部品（yt-dlp・文字認識・動画処理）と、YouTube取得に必要な Deno が入ります。
   途中で「このアプリがデバイスに変更を加えることを許可しますか」と出たら「はい」。

■ 毎回の使い方
1. run.bat をダブルクリック
2. 黒い画面に配信アーカイブのURLを貼り付けて（右クリックで貼り付け）Enter
3. 放置。5時間の配信で15〜30分ほど（音声と低画質の映像をダウンロードして解析するため）
4. 終わると Chrome でレポートが開きます

チャットだけ急いで見たいときは run_chat_only.bat（数分で終わります）。

■ レポートの見方
・序盤と後半の比較 …… コメント/分・同じコメント率・声・喋る量などを並べ、「後半は何倍か」を表示
・タイムライン …… 横軸が配信の時間。1マス30秒。明るいほどその配信の中で高い。
　　一番上の帯：緑＝序盤（雑談・練習）、紫の番号＝試合。黄色の▼＝見どころ候補
　　右上で「折れ線」に切り替え、表示範囲を「後半」や「試合3」などに拡大できます
　　グラフをクリックすると、その時刻の少し前からYouTubeで開きます
・試合ごと …… 試合ごとの盛り上がりの比較。行をクリックするとタイムラインがその試合に拡大
・見どころ候補 …… 「序盤／後半」で絞り込み可。時刻を押すとYouTubeでその場面から再生

結果は output フォルダの中に動画ごとに保存されます（見どころレポート.html、見どころメモ.txt）。
同じ動画をもう一度実行すると、解析済みの結果を使うので一瞬で終わります。

■ 各指標の意味
・コメントの加速度：直前の30秒からコメントがどれだけ増えたか（急に湧いた場面で高くなる）
・同じコメントの流れる確率：30秒の中で一番多いコメント（「草」「888」など）が全体に占める割合
・声の大きさ：音声の大きさ（30秒の中の大きい方の値）。叫びや盛り上がりで上がります
・喋る量：30秒の中で喋っていると推定された時間の割合
　※ゲーム音と声は混ざっているため、声の大きさ・喋る量は「推定」です。
　　配信どうし・パートどうしの比較の目安としてご覧ください。

■ 調整（config.py をメモ帳で開いて変更）
・BIN_SEC：グラフの1マスの秒数（初期値30）
・MIN_SPEED：見どころ候補の出やすさ（下げると増える）
・KEYWORDS：検知するワード。配信者ごとの定番コメントを追加できます
・WEIGHTS：盛り上がりスコアの各指標の重み
・MATCH_TEXT：試合の区切りに使う文字（初期値 RANKED MATCH）
・KEEP_MEDIA：True にするとダウンロードした音声・映像を残します
設定を変えたら、同じURLでもう一度実行すれば反映されます（ダウンロードはやり直しません）。
※試合検知の設定を変えたときは、run.bat の画面で URL の後ろに  --redo-media  を付けて実行。

■ 「RANKED MATCH」の検知について
初回は文字認識で画面を探し、見つけるとその見た目を覚えて、以降は高速に照合します。
覚えた手本は次の配信でも使います。検知がずれるときは templates フォルダの README を見てください。
（検知できた場面の画像が、output の中に match_detected_sample.png として保存されます）

■ うまくいかないとき
・「python が見つからない」→ Python インストール時の「Add python.exe to PATH」のチェック漏れ。入れ直してください
・setup.bat の途中でエラー → Python 3.13 を入れ直して再実行してください
・取得でエラー → setup.bat をもう一度実行（yt-dlp が最新になり、YouTube側の変更に追従します）
・「RANKED MATCH」が見つからない → templates フォルダに、その場面のスクリーンショットを
　ranked_match.png という名前で置いて、URLの後ろに --redo-media を付けて再実行
・メンバー限定・年齢制限の配信、配信中（ライブ中）の配信は解析できません

■ 注意
・視聴者数の推移は YouTube がアーカイブに残さないため使えません。
・切り抜きの際は、配信者の切り抜きガイドラインを確認してください。
