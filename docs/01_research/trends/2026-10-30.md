# 動向レポート 2026-10-30（初回。前回レポートなし）

確認日はすべて 2026-10-30。「事実」は出典で確認した内容、「推測」は私の判断。確認できなかったものは「未確認」。

## 0. 急ぎの対応（冒頭）
急いで壊れるものはありません。ただし次の2点は早めの対応を勧めます。

1. **certifi の重大な脆弱性（GHSA-6q48-6c7w-9gw2、深刻度 Critical）**
   - 事実：certifi 2026.10.18 より前の版は、鍵が漏れた emSign ルート証明書を含み、通信を盗み見・改ざんされるおそれがある。2026.10.19 以降に上げることが推奨されている（2026-10-20 公表、10-26 更新）。yt-dlp 2026.10.21 のリリースノートも同件に触れ、古い版は中間者攻撃に弱いと警告している。
   - 事実：この調査PCの certifi は 2026.10.23 で対応済み（pip list で確認）。
   - 推測：利用者のPCでは、`app/setup.bat` の `pip install -U "yt-dlp[default]"` だけでは、すでに入っている古い certifi が上がらない可能性がある（pip の標準の更新方針は「必要なときだけ」。未検証）。
   - 影響：YouTube と通信する取得処理（hl_fetch.py）と、rapidocr の初回モデル取得が対象。
   - 期限：次の配布前までに setup.bat で certifi を明示的に更新する（案：`pip install -U certifi` を追加）。社長判断は不要と見込む（取得先は変わらない）が、課長・部長で確認。
   - 出典：https://github.com/advisories/GHSA-6q48-6c7w-9gw2 、https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.21

2. **Python 3.10 のサポート終了（2026年10月）に伴う下限の引き上げ**
   - 事実：yt-dlp 2026.10.26 で Python 3.10 のサポートを削除（最低 3.11）。PyPI の requires_python も >=3.11。Windows 公式バイナリは Windows 10 以降が必須になった。
   - 影響：Python 3.10 の利用者は `pip install -U yt-dlp` で最新に上がらず、YouTube側の変化に追従できなくなる。README に「Python 3.11 以上」と書かれているか要確認（未確認）。
   - 期限：次回の README・setup.bat の見直しの時点。
   - 出典：https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26 、https://pypi.org/project/yt-dlp/

## 2. yt-dlp とYouTube側の変化
直近のリリース（GitHub Releases で確認）
| 版 | 日付 | 主な内容 |
|---|---|---|
| 2026.10.26 | 2026-10-26 | Python 3.10 削除（最低3.11）、Windows バイナリは Windows 10 以降、brotli 1.2.1・curl-cffi 0.17.0 に更新 |
| 2026.10.21 | 2026-10-21 | YouTube：tv_samsung クライアントを追加し既定に、初期データ取得の修正、web_embedded に Safari の User-Agent。certifi 脆弱性の警告 |
| 2026.08.19 | 2026-08-19 | YouTube：visionos クライアント追加、android_vr を既定から外す、ライブの断片生成の修正。`number_of_digits`・`random_uuidv4` を非推奨 |
| 2026.07.04 | 2026-07-04 | 推奨Pythonを3.11へ引き上げ。`make_dir` を非推奨 |

出典：https://github.com/yt-dlp/yt-dlp/releases （個別：/tag/2026.10.21、/tag/2026.10.26）。8件取得を試みたが、取得できたのは上の4件分のみ。2026.08.19〜2026.10.21 の間の版は未確認。

- 事実：既定のクライアントが短期間で入れ替わっている（android_vr を外し、tv_samsung を既定に）。YouTube側の変更に合わせて yt-dlp が頻繁に更新されている。
- 推測：当アプリは `yt_dlp.YoutubeDL` を既定のクライアントのまま使い（hl_fetch.py で `extractor_args` の指定なしを確認）、これは追従しやすい書き方。ただし古い yt-dlp のままだと取得が失敗する公算が大きい。README の「取得でエラー → setup.bat を再実行」の案内は妥当。
- 推測：yt-dlp の更新は週〜月単位で続くため、利用者向けに「更新しないと動かなくなる」ことの案内を引き続き強調するとよい。

### JavaScript ランタイム（EJS）
- 事実：YouTube の取得には JS ランタイムが必要。Deno が推奨・既定で有効（最低 2.3.0）。Node は最低 22.0.0 で `--js-runtimes node` が必要。Bun は非推奨（1.3.14 まで）。QuickJS も可。出典：https://github.com/yt-dlp/yt-dlp/wiki/EJS
- 事実：解法スクリプトは `yt-dlp-ejs` で提供され、`yt-dlp[default]` に含まれる。yt-dlp の更新と同時に更新すること。古い版は予告なく切り捨てられうる。同上。
- 影響：当アプリの setup.bat は `yt-dlp[default]` と Deno（winget）を入れており、方針は現行の要件に合っている。調査PCの Deno 2.9.8 は最低要件（2.3.0）を満たす。
- 未確認：利用者のPCの Deno の版。winget で `where deno` が見つかると導入を飛ばすため、古い Deno（2.3.0 未満）が残るおそれ（推測）。
- 未確認：PO Token と SABR について、2026年の最新の状況（今回の検索では 2026年の情報が見つからなかった）。当アプリは音声・映像・チャットを yt-dlp 任せで取得しており、PO Token の扱いも yt-dlp が担う。実配信での確認（smoke-test）で失敗が出たら再調査。「/deep-research 推奨」：YouTube 側の取得制限（PO Token・SABR）の2026年の動向。

## 4. その他の採用ライブラリ
- numpy 2.5.4：requires_python >=3.12。**Python 3.11 の環境では numpy が 2.5 に上がらない**（旧版が入る）。事実は PyPI の表記。当アプリで問題が出るかは未検証。
- onnxruntime 1.31.1：Python 3.11〜3.14 の wheel あり。**Python 3.15 は未対応**（未確認ではなく、wheel 一覧に cp315 が無い事実）。新しいPythonが出たときは onnxruntime が最後に対応しがち（推測）。仕分け表の「Python の新しい版への対応時期に注意」は引き続き有効。
- opencv-python-headless 5.0.0.93：メジャー版が 5 になっている（2026-07-02）。**API の破壊的変更の有無は未確認**。調査PCでは 5.0.0.93 が入っている。テスト実施で動作を確かめた記録は今回は無し（未確認）。品質保証課への確認を依頼。
- rapidocr 3.10.0：Apache-2.0。依存に Shapely・pyclipper・Pillow・opencv-python-headless 等。初回のモデル取得時に通信があり、certifi の問題（0章）の対象になる。モデルのライセンス（MODEL_LICENSES.md が同梱）は未確認。仕分け係へ引き継ぎ。
- imageio-ffmpeg 0.7.0：2026-10-28 公開（調査日の2日前）。リリースノートの内容は「書き出しの fps を rational で渡す」程度で、同梱 ffmpeg の版は未確認。当アプリは ffmpeg の実行ファイルを取得するだけの使い方（hl_fetch.py）。影響は小さい見込み（推測）。
- scipy 1.18.1：開発・テスト用のみ。製品への影響なし。
- Python 新版：3.13.14 の調査PCで全ライブラリが入っている。3.14 は、numpy・onnxruntime・scipy・opencv が wheel を提供（事実）。3.15 は numpy・scipy・yt-dlp のみ確認（onnxruntime は未対応）。
