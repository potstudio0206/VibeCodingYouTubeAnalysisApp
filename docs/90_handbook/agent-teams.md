# エージェントチーム（使う場面を限定）

エージェントチームは、複数の Claude（課長など）が互いに直接話し合いながら進める、Claude Code の実験的な機能です。
トークンを多く使うため、この組織では次の2つの場合だけ使います。

| 場面 | 起動（このリポジトリのフォルダで） | 手順 |
|---|---|---|
| 原因の分からない不具合の究明 | `scripts\team.bat bug "症状"` | スキル /team-bug |
| 両部にまたがる判断 | `scripts\team.bat cross "決めたいこと"` | スキル /team-cross |

## 仕組み
- `scripts\team.bat` は、環境変数 `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` を付けて Claude Code を起動し、隣の相手リポジトリも読めるようにします（`--add-dir`）。
- リーダーは部長です。部長が課長・係長の定義を使ってチームメイトを起こし、互いに仮説を反証させたり、意見を出し合わせたりします。
- 結果は、不具合なら `docs/07_ops/incidents/INC-xxxx-*.md`、判断なら `docs/00_status/decisions/` に残ります。

## 注意
- 普段のセッションでは有効にしません。有効にすると、普段の依頼でもチームが作られてしまいます。
- Windows Terminal では画面の分割表示はできません（1つの画面の中で切り替えて見ます。↑↓で選んで Enter）。
- チームでの調査では製品コードを直さず、直すのは通常のセッションで /bugfix-pipeline として行います。
