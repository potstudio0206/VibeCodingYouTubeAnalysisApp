# 社長向け：この組織の使い方

あなた（社長）の仕事は、**部長に指示を出すこと**と、**判断待ちに答えること**だけです。

## 1. 仕事を頼む
次のどちらかで頼みます。
- **GitHub で頼む（おすすめ）**：このリポジトリの Issues →「New issue」→「社長指示」を選んで書く。定期の巡回で部長が受け付けます。
- **直接話す**：このリポジトリのフォルダで Claude Code を開くと、相手は部長です（`.claude/settings.json` で部長として起動します）。「〜を作って」「〜が動かない」と話しかけます。

## 2. 判断待ちに答える
- 部長が、ラベル「社長判断」の Issue を立てます（GitHub の通知・スマホアプリに届きます）。
- 選択肢の番号や指示を、その Issue にコメントするだけです。次に部長が起動したときに読み取り、作業を再開します。

## 3. 状況を見る
- **日報**：ラベル「日報」の Issue（月ごとに1件、毎日コメントが付きます）
- **進捗ボード**：`docs/00_status/board.md`
- **PR**：部長が作るPR（新機能・リリースは、あなたの承認後にマージされます）

## 4. 特別な相談（エージェントチーム）
原因の分からない不具合や、両部にまたがる判断のときだけ、このフォルダで次を実行します（トークンを多く使います）。
- 不具合の究明：`scripts\team.bat bug "症状"`
- 部をまたぐ判断：`scripts\team.bat cross "決めたいこと"`

## 5. 止める・変える
- 定期実行を止める：Claude デスクトップアプリの「Scheduled（スケジュール）」で、該当のタスクを Paused にします。
- 組織の決まりを変える：`CLAUDE.md`（共通ルール）や `.claude/agents/`（役割）を変えます。部長に頼むと、変更の前に確認が出ます。
- 自動でマージさせたくない：`.claude/settings.json` の `permissions.allow` から `"Bash(gh pr *)"` を外し、`"ask"` に `"Bash(gh pr merge *)"` を加えます（マージのたびに確認が出ます）。
