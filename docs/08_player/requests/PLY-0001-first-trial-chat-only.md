# PLY-0001 プレイヤー要望書（約2.4時間の配信から、10分で切り抜き候補を3つ決める）

詳細メモ：docs/08_player/notes/2026-10-30-good.md、2026-10-30-bad.md

## 試用の筋書きと結果（かかった時間・手数）
- 筋書き1「約2.4時間の配信から、10分で切り抜き候補を3つ決める」：レポートの表を上から読み、追加クリック0回で上位3件（2:23:30、1:20:30、0:17:00）に絞れた。ただし1位は配信終了直前で、候補として使えるか未確認。YouTubeでの再生確認は未実施のため「10分で決められたか」は計測していない。
- 筋書き2「序盤の雑談と後半の試合の比較」、筋書き3「試合ごとの見どころ」：できなかった（P-01）。
- 試用の前提（判断の記録）：社長不在の自動実行。実配信の解析（約8分以上、画面解析が5分以上）は、課長の実行が500秒の時間制限で打ち切られ、画面解析まで終わらなかった。そのため既存のチャットのみ解析の結果（fPnkoOtQIyE）を使った。画面解析が未完の原因が製品側か、打ち切りのためかは未確認。したがって P-01 の「画面解析の失敗」は製品の不具合と断定しない。

## 要望（優先度つき）
1. 高：チャットだけの結果を先に出し、画面解析は後から反映・再開できるようにする（P-01〜P-03）。
2. 高：解析できなかった項目と理由を、レポートとメモの両方に表示する（P-01、P-04、P-08、P-09）。
3. 中：候補の絞り込み（件数指定、最低コメント数、終了際の印）（P-05〜P-07）。
4. 低：表示の補足（ピーク時刻、倍率の基準、同じコメント率の注意書き）（P-11〜P-13）。
- 保守運用課への共有：P-02 の所要時間が README の記載と合うかの実測、P-10 の中断跡の確認。
