# 判断待ちIssueの起票（部長だけが使う）

件名: $ARGUMENTS

1. 同じ件の未解決Issueが無いか確かめる：
   `gh issue list --label 社長判断 --state open --search "<キーワード>"`
   あれば、新しく作らずにコメントで追記する。
2. 本文を一時ファイル（リポジトリの外。例：スクラッチの場所）に、次の形で書く。@ で人の名前を書かないこと（通知が飛ぶため）。

```
## 判断してほしいこと
（1〜2文）

## 選択肢
1. 【推奨】…（理由、影響、手間・期間）
2. …

## 背景
（なぜ判断が必要か。関係する課の意見）

## 判断しない場合の影響・期限

## 関連
（REQ / DD / PR / Issue の番号、ファイル）

---
起票：アプリケーション部 部長（Claude）
返答：このIssueに、選んだ番号や指示をコメントしてください。
```

3. 起票する：`gh issue create --title "[判断待ち] <要約>" --label 社長判断 --body-file <ファイル>`
   両部にまたがる件は `--label 部門間` も付ける。共通指標仕様の件は `--label 共通仕様` も付ける。
4. docs/00_status/board.md に「判断待ち #番号」と書き、その件の作業は止める。
5. 返答の取り込み：起動時ブリーフィングに★が付いたら、社長のコメントを読み、決定を関連書類に記録し、「承知しました。〜で進めます」とコメントしてクローズする。
