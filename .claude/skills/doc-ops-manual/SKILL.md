# 保守運用書の書き方

- 置き場所：docs/06_qa/ops-manual.md（1つの文書を更新し続ける）
- 保守運用課が、そのまま実行できる細かさで書く。コマンドはコピーして使える形で。

構成：
1. 定期作業（いつ・誰が・何を）
2. 実配信での動作確認（スモークテスト）の手順
3. 依存ライブラリの更新手順
4. よくある障害と対応（エラーの文言 → 原因 → 対応）
5. 復旧手順（前の版に戻す）
6. 確認用URLの管理（ops/smoke-urls.txt）
7. 変更履歴
